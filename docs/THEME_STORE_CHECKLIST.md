# Submission matrix — initial, not a completed compliance audit

Source checked 2026-10-25:
https://shopify.dev/docs/storefronts/themes/store/requirements

| Area | Current evidence | Gate still open |
|---|---|---|
| Permitted source | Skeleton parent pinned, license preserved | Original finished design and full eligibility review |
| Templates/groups | JSON templates and header/footer groups restored | Contact template absent; every template must be tested |
| Product customization | Main product blocks, app block, Custom Liquid code | Editor reordering/app lifecycle; featured product support |
| Commerce | Native product/cart forms; selected variant server output | Real Shopify purchase-path tests; subscriptions, pickup, high variants |
| Discovery | Inherited collection/search plus homepage collection | Predictive search, filters/sorting, mega menu |
| Electronics | Merchant facts/compatibility/box contents | Comparison, summary, variant scope, recommendations |

| Performance | No live measurements | Minimum average Lighthouse performance 60 and accessibility 90 across home/product/collection, desktop and mobile, benchmark content |

| SEO/media | Inherited meta tags; product structured_data | Rich-results tests, video/model media, all responsive images |
| Custom Liquid | Section and product block added | Real editor/app integration |
| Demo/support | No store selected, no support channel published | Client transfer demo, documentation/contact, release materials |

Additional official areas still require line-by-line completion: exclusivity,
all required features (including localization, unit prices, accounts/Follow on
Shop, gift cards and accelerated checkout), color schemes, font picker, naming,
responsive images, browser compatibility, social metadata, customer privacy,
version/release notes and ongoing merchant support. Do not treat this table as
covering every official checkpoint. No acceptance or submission readiness claim.
